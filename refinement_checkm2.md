# Refinement and Quality Assessment Pipeline (metaWRAP with CheckM2)

This document describes the refinement workflow used in the study:

**Comprehensive benchmarking of metagenomic binning tools reveals key factors for improved genome recovery.**

The pipeline combines metaWRAP-based bin refinement with CheckM2-based quality prediction. All wrapper scripts used to orchestrate these steps are provided in the `scripts/` directory of this repository.

---

## Overview of Workflow

The refinement and evaluation process consists of the following steps:

1. Filtering bins by size threshold
2. Bin refinement using metaWRAP (`binning_refiner.py`)
3. Quality assessment using CheckM2 (`checkm2 predict`)
4. Consolidation of refined bin sets
5. Dereplication of contigs across bins

This workflow was applied consistently across all benchmarking datasets described in the manuscript.

## Execution

The refinement workflow is executed via the wrapper scripts located in the `scripts/` directory.

**Example command structure:**

```
python refinement_checkM2.py OUTPUT_DIR BINS_A BINS_B BINS_C THREADS
```

**Arguments:**

* `OUTPUT_DIR` – empty output directory
* `BINS_A`, `BINS_B`, `BINS_C` – directories containing bin FASTA files (.fa / .fasta)
* `THREADS` – number of CPU threads for CheckM2

Users must ensure that metaWRAP and CheckM2 are correctly installed and accessible in the system environment before running the pipeline.

---

## Output Structure

The pipeline generates:

* Refined bin directories (pairwise and three-way refinement)
* CheckM2 quality report directories
* Consolidated bin sets
* Final dereplicated bin collections

Quality metrics generated by CheckM2 are subsequently used for benchmarking analyses as described in the manuscript.
